# Beer Stocking

A phone-friendly stocking tool: sign in, pick Backstock or Truck Day and a store, tap in counts, and get a pull list by brand. History shows totals by store, week, month and product.

- `index.html` is the whole app.
- `beer-img.js` holds the product photos and logos.

Accounts, lists and history are saved in the browser on each phone. Nothing is sent to a server.
